# Lab08 — Mockito

`CourseRegistrationServiceTest` нь сан болон и-мэйл илгээгчийг Mockito mock-оор орлуулж, бүртгэлийн бизнес логикийг тусад нь шалгана. Тестийн 8 аргаас A8 параметржүүлсэн тестийн 3 мөр тус бүрдээ тоологддог тул нийт 10 тест ажиллана.

A8 тестийн мөр бүр зөвхөн тухайн хувилбарт хэрэгтэй stub-үүдээ тохируулдаг. Иймээс ашиглагдаагүй stub үүсэхгүй бөгөөд `lenient()` хэрэглэх шаардлагагүй.

Тест ажиллуулж, гаралтыг `results/mvn-test.txt` файлд хадгалах:

```sh
mkdir -p results && mvn test 2>&1 | tee results/mvn-test.txt
```
